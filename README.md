# 🌟 Claude Album

## 孫の成長記録：新生児～8歳（700枚の8年間タイムライン）

---

## 📖 プロジェクト概要

このプロジェクトは、**2018年4月～2024年9月** の間に記録された **700枚の写真** を通じて、孫の成長を可視化・分析するデジタルアルバムです。

### 🎯 特徴

- **完全な成長記録**：新生児（0ヶ月）から8歳（96ヶ月）までの全発達段階をカバー
- **親からの視点**：親の記録戦略の変化から、子育ての現実を読み取る
- **発達データ**：各月齢での身体発達、認知発達、情動発達、社会性を可視化
- **インタラクティブ**：月齢スライダーでタイムラインを自由に移動
- **家族共有**：リンク共有で誰でもアクセス可能

## 🎨 使い方

### **ブラウザで開く**

1. `index.html` をブラウザにドラッグ&ドロップ
2. または、GitHub Pages URL を開く（公開時）

### **インタラクティブ機能**

```
📅 月齢スライダー
   → 0～96ヶ月を自由に移動
   → リアルタイムで発達情報が表示される

🏷️ バッチフィルター
   → 特定のバッチだけ表示
   → または全バッチを表示

📊 発達マイルストーン
   → その月齢での身体発達
   → 認知発達、情動発達、社会性
   → 親からのコメント
```

## 📈 発達分析の視点

### **バッチ1-7（0-6ヶ月）：新生児から乳児初期へ**
- 新生児反射から目的的な動きへの移行
- 視線追跡の開始
- 社会的微笑の確立
- 親の細心な毎日複数回の記録

### **バッチ2（6-14ヶ月）：乳幼児前期**
- 座位の安定化
- クローリング（腹ばい移動）から つかまり立ちへ
- 物への執着と探索行動の急増
- 週3-4回の記録

### **バッチ3（14-19ヶ月）：乳幼児中期**
- 独立歩行の開始
- 語彙爆発期（理解語彙から発話語彙へ）
- 初期イヤイヤの本格化
- 自我の確立

### **バッチ4（24-30ヶ月、2-2.5歳）：初期幼児期**
- 二語文への移行
- 第二次イヤイヤの本格化
- 『一人でやる』という独立性の強い欲求
- **COVID-19パンデミック期間** — 親が困難な時期でも記録を続けた

### **バッチ5（36-48ヶ月、3-4歳）：幼児期**
- 複雑な社会性の芽生え
- 学習準備性の確立
- **幼稚園入園** — 親からの心理的距離が拡大
- 親が『見守る親』へシフト開始

### **バッチ6（48-96ヶ月、4-8歳）：幼稚園年長～小学校中学年**
- 社会的自立の深化
- 読み書き能力の発展
- **小学校入学** — 本格的な学習と社会適応
- 親が『大切な瞬間を選別して記録する親』へ

## 💡 読み取れる発達特性

### **言語能力が高い**
- バッチ3で語彙爆発が明確
- バッチ5で複文構成確立
- バッチ6で読み書き能力が急速に発展

### **独立心が強い**
- イヤイヤの強さと持続期間
- 『一人でやる』という欲求の表現
- 親への依存と自立のバランスが取れている

### **学習意欲が高い**
- バッチ5で文字・数への関心の急速な高まり
- バッチ6で集中力が継続的に向上
- 継続的な『なぜ？』という質問

### **社会性が発達している**
- バッチ5で友人関係の本格化
- バッチ6で『親友』という特定の友人関係の形成
- グループでのリーダーシップとフォロワーシップの両立

### **親からの自立がスムーズ**
- バッチ4以降の記録頻度の段階的減少
- 子どもの自立に応じた親の『見守る親』へのシフト
- 信頼関係に基づいた自然な自立
